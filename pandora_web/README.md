# 潘多拉 Web 管理端

React 18 + TypeScript + Vite，系统管理员专用。当前 Web 提供用户管理、组织与团队人员查看、事件纪及独立操作记录查询。日志、统计、角色权限配置和系统配置页面已取消，Android 功能由移动端负责。

## 本地运行

已有依赖时运行：

```powershell
cd pandora_web
npm run dev
```

默认访问 http://localhost:5174。首次安装依赖使用 `npm ci`。

真实后端推荐配置：

```dotenv
VITE_API_BASE=/api
VITE_USE_MOCK=false
VITE_PROXY_TARGET=http://localhost:8080
```

`/api` 通过 Vite 代理访问后端。管理员密码由后端 `ADMIN_INIT_PASSWORD` 初始化，不在前端预置。个人 `.env.local` 不应随本次改动提交；此文件历史上已被跟踪，不能只靠忽略规则阻止提交。

## 当前能力与接口缺口

下表为既有接口的本地验证情况；服务器部署和后端维护由后端同学负责，不能据此认定线上已可用。新增的业务操作记录对接要求见下文。

| 功能 | 真实后端 | 前端行为 |
| --- | --- | --- |
| 登录、当前身份、退出 | 已实现 | 真实请求，限制 ADMIN；过期后清理身份并回登录 |
| 事件纪查询、新增、编辑 | 已实现并联调 | 服务端分页，起止时间按整点保存；事件删除未定义 |
| 用户、组织、团队成员、审计 | 已实现并联调 | 真实查询与维护，失败不使用模拟数据兜底 |
| 组织介绍、手机号、性别和身份证号 | 已实现 | 新开户持久化，管理员可查询；旧数据不补造，已有账户名与手机号不开放修改 |

已有接口遵循 `documents/后端接口文档.md` 的 `{code,message,data}` 响应；分页为 `{items,page,size,total}`。HTTP 失败、业务失败、HTML 或不完整分页都会显示错误，不能变成空列表或成功提示。

`src/api/capabilities.ts` 已开放既有管理能力；使用不兼容的后端会明确报错，由后端同学补齐对应接口。移除权限配置页面不改变角色选择、管理员限制或后端权限校验。既有启动步骤见 [后端启动与验收](../documents/Web管理端后端启动与验收.md)。

## 演示模式

仅开发环境在登录页主动勾选“演示模式”，使用 admin 和任意非空密码。正式构建忽略演示缓存与 VITE_USE_MOCK，隐藏演示及联调自检入口，始终请求真实后端。该模式不验证真实密码，不访问后端。页面始终显示演示标识。

- 用户演示新增、编辑、启停、移除状态由数据层统一保存在本地浏览器，可用“恢复演示数据”清除；用户页和团队人员使用同一份演示状态，不能作为服务器数据或安全验证证据。
- 组织和事项演示修改在当前页面会话内有效，刷新后恢复默认模拟数据。
- 切换真实/演示模式会清理身份，必须重新登录。
- 只有演示提供“移除用户”，真实后端无用户删除接口。
- 接口联调一键自动覆盖管理员端 21 个接口及团队成员筛选，共 22 项检查。自动生成参数、查询编号、执行写入与回查，无需逐项填写。只修改本次创建并核实归属的测试记录，账号在结束后停用，临时部门和团队删除；因现有接口不支持删除用户和事件，将保留一个停用测试账号和一条标记事件，开始前及报告中均会说明。失败、缺少前置数据、清理失败明确展示，密码和令牌不写入报告，当前管理员会话保持。

## 手机号辅助开户、身份证与初始密码

- 新开户身份证号必填，检查18位结构、出生日期与校验位，末位小写 x 自动转大写。规则有效不等于实名核验。用户详情默认遮蔽号码，可主动查看。号码不经导出或前端操作记录输出。
- 新建用户先填 11 位手机号，账户名自动填入；手动修改账户名后，继续改手机号不会覆盖它，可点击“恢复手机号”重新联动。
- 重新打开新增表单会清空手机号、账户名、初始密码和手改标记。编辑可填新身份证号，留空保留原号。提交更正时会校验、排除当前用户查重并回读确认。旧后端需支持可选 `idNumber` 后才能保存。接口契约见[管理端数据校验与完整性后端要求](docs/管理端数据校验与完整性后端要求.md)。
- 开户、编辑和重置使用逐字段校验，失焦显示问题，提交时定位首个无效字段。开户提交前分批核对账户名、手机号和身份证号，停用账号也参与核对，同名人员可正常开户。账号或资料冲突只显示对应字段。服务端资料缺失或其他管理员并发提交时，最终唯一性依赖后端和数据库约束。
- 初始密码可生成、显示和复制。重置弹窗默认生成一组 16 位随机强密码，支持重新生成。两处手填均校验至少 12 位、包含大小写字母、数字和符号，UTF-8 最多 72 字节。密码默认遮蔽，取消或成功保存后清空。演示模式不会保存或验证真实密码。
- 真实接口接入后，创建请求同时提交独立的 username、phone 和 password；由后端验证并将密码哈希存入数据库。后端应返回用户资料，不返回密码或密码哈希。
- 用户管理、phone 等字段与 BCrypt 入库已通过真实数据库联调。密码重置、账号启停及资料变更撤销旧会话；当前登录账号自身变更后可能需要重新登录。具体约定见 documents/后端接口文档.md 第 3.1、15 节。

## 路由

- `/login`：登录。
- `/users`：用户管理或接口待接入提示。
- `/org`：组织结构与团队人员弹窗。
- `/audits`：操作记录，按操作者、业务、动作和日期分页筛选，并查询字段变化。
- `/matters`：左侧独立入口“事件纪”，维护公司重要事件的标题、备注、排序和开始/截止时间。名称与手机端保持一致，沿用 `/company-matters` 接口及既有字段。
- `/debug`：仅开发环境提供一键自动接口联调；正式构建访问此地址按页面不存在处理。最新后端的路由覆盖与兼容问题见 [接口核对与联调](docs/接口核对与联调.md)。
- 原 `/logs`、`/stats` 不恢复，访问按不存在页面处理。

## 界面与用户列表

- 页面采用浅色导航、浅灰内容区、白色卡片和蓝色操作色，统一文字层级与线条图标；窄屏保留完整导航，宽表格在自身容器内横向滚动。登录页在桌面采用双栏，窄屏收起介绍区。
- 用户列表合并姓名与账号、部门与团队，保留编辑和详情入口；在用户详情中执行启停、重置密码及仅演示模式的移除，危险操作需确认。
- 正文、输入和表格主体为16px，辅助文字至少14px，按钮/输入框主要尺寸至少44px；新增用户表单按账号身份和组织归属分组，错误定位到字段。
- 用户搜索、角色/状态筛选和分页统一通过 `GET /users` 的查询参数处理，每页 10 人，人数使用服务器返回的当前查询 `total`。真实模式不合并、修改或重置本地演示补丁，成功写入后重新查询服务器，失败保留表单和明确错误。
- “导出当前页”只导出当前显示页，不把第一页数据当成全量；移除最后一页最后一人时自动返回有效页码。
- 弹窗覆盖整个视口，限制键盘焦点、锁定背景滚动并在关闭后恢复焦点；长表单在弹窗内部滚动，取消、保存及错误提示位置统一。
- 新增和编辑用户时，点击弹窗外或按 Escape 会保留表单。底部「取消」可放弃填写。姓名须由文字组成，文字之间可用空格、中点或连字符。
- 真实部门创建使用 GET /companies 返回的唯一公司 ID，归属不明时禁用创建，不默认写入公司 1。公司、部门和团队返回完整元数据数组；用户、审计和事项保持分页。

## 团队人员与事项时间

- 组织结构采用部门选择与团队列表布局。「查看介绍」显示部门介绍与负责人，缺位、资料不一致和读取失败分别提示。新建部门、团队检查名称、同级重名、介绍和归属。名称须包含文字，介绍可留空，填写时须包含文字。同级名称查重忽略大小写、全半角及多余空白，提交前重新读取同级组织。
- 在组织管理的团队列表点击“查看人员”，可按姓名或账号搜索，分页显示姓名、账号、角色和状态。真实接口复用 `GET /users?teamId=...&keyword=...&page=...&size=...`，以稳定团队 ID 筛选，响应保留组织 ID。
- 演示团队列表合并本浏览器的新增、编辑、停用和移除记录；旧演示记录仅在部门和团队名称能唯一定位时补足 ID。真实模式不读取这些本地补丁，不接受团队归属不匹配的响应。
- 事项新建、编辑分别选择开始/截止日期和 `00～23` 小时，不提供分钟选择，分钟和秒固定为 `00`。列表显示北京时间，例如 `2026-10-29 09:00`。
- 事件纪前端限制最多 10 条，创建前重新读取服务器总数。满额时仍可编辑，超过 10 条的历史记录可翻页查看。跨管理员并发的硬上限需要服务端约束。列表按服务端顺序显示连续序号。新增和编辑保存时，显示顺序须为 1 到 2147483647 之间的整数。历史 0 或负值仍可查看，编辑时须改为正整数。
- `startDate` 与 `deadline` 保留字段名，内容调整为带 `+08:00` 的整点时间戳，例如 `2026-10-29T09:00:00+08:00`；允许同一整点，截止不得早于开始，也不受浏览器所在时区影响。
- 旧纯日期记录仍按日期展示，编辑时必须明确补选小时，不自动填为零点；缺失时间显示“未设置”。
- 起止时间由 V7 的 TIMESTAMPTZ 字段保存，后端独立验证北京时间整点；真实写入口已开放，保存后重新查询服务器。
- 操作记录仅查询工作日志、派发任务，默认与重置后为工作日志，每次请求均明确限定类型；不显示自建任务、员工账号、部门、团队、公司事项等其他记录。支持按操作者、动作、北京时间日期范围查询；详情展示业务编号、来源、结果、摘要和字段变化。日志不可删除，任务删除及其留痕由后端和手机端同学实现，Web 只查询实际返回的记录，不提供业务删除或恢复按钮。历史缺失字段不补造，错误响应明确提示。演示记录是固定样例，不代表真实操作已被服务端审计。
- 接口覆盖与一键测试方法见 [接口核对与联调](docs/接口核对与联调.md)；日志任务动作、查询参数、字段和开户约束见 [日志任务操作记录对接](docs/日志任务操作记录对接.md)。本轮交付只包含管理员前端及其协作说明。

## 人工验收清单

1. 真实管理员能登录，普通角色不能进入 Web；错误密码和网络失败不进入演示。
2. 真实模式公司事项能翻页；无数据、无权限、服务故障各自显示正确状态。
3. 真实模式未实现模块说明缺口，不发管理请求、不提供可提交入口。
4. 令牌过期后回登录，权限和身份缓存清除；退出失败时仍清理本地会话并提示。
5. 演示中新建、编辑、启停用户，部门/团队归属正确；密码生成和重置交互可用。
6. 团队成员包含团队负责人和员工；搜索、分页、空团队和跨团队隔离正确，本地用户变更可在演示中回显。
7. 事件纪在左侧独立显示，菜单、页面标题、登录页及新建/编辑文案统一；验证仅可选择小时、新增编辑回显、缺失小时、同日倒序、跨日零点、同一整点和旧纯日期的兼容。
8. 浏览器窄窗口下检查导航、表格滚动和弹窗。
9. 导航、自检与组织标签没有日志、统计、角色权限配置、系统配置入口；审计可查询并查看具体记录，用户角色选择保留。
10. 用户数据超过一页时按后端 `total` 翻页，跨页搜索可找到目标；真实模式不显示演示账号，导出文件仅含当前页。
11. 弹窗遮罩覆盖整个窗口，Tab 焦点留在弹窗内。新增和编辑用户时点遮罩或按 Escape 保留表单，取消后恢复焦点。390px 窗口导航可见，页面无整体横向溢出。
12. 用户详情中的启停确认可取消并恢复焦点，重置密码对话框可正常切换；部门筛选只显示所属团队，登录及四个主页面在窄屏可正常使用。
