# 潘多拉 Web 管理端

React 18 + TypeScript + Vite，系统管理员专用。当前 Web 提供用户管理、组织与团队人员查看、公司十大事项及审计查询。日志、统计、角色权限配置和系统配置页面已取消，Android 功能由移动端负责。

## 本地运行

已有依赖时运行：

```powershell
cd pandora_web
npm run dev
```

默认访问 http://localhost:5174。首次安装依赖使用 `npm ci`。

真实后端推荐配置：

```dotenv
VITE_API_BASE=/api
VITE_USE_MOCK=false
VITE_PROXY_TARGET=http://localhost:8080
```

`/api` 通过 Vite 代理访问后端。管理员密码由后端 `ADMIN_INIT_PASSWORD` 初始化，不在前端预置。个人 `.env.local` 不应随本次改动提交；此文件历史上已被跟踪，不能只靠忽略规则阻止提交。

## 当前能力与接口缺口

2026-10-29 本地工作区实现与真实 PostgreSQL 联调状态；尚未代表服务器已部署：

| 功能 | 真实后端 | 前端行为 |
| --- | --- | --- |
| 登录、当前身份、退出 | 已实现 | 真实请求，限制 ADMIN；过期后清理身份并回登录 |
| 公司重要事项查询、新增、编辑 | 已实现并联调 | 服务端分页，起止时间按整点保存；事项删除未定义 |
| 用户、组织、团队成员、审计 | 已实现并联调 | 真实查询与维护，失败不使用模拟数据兜底 |
| 组织介绍、手机号、性别和身份证号 | 已实现 | 新开户持久化，管理员可查询；旧数据不补造，已有账户名与手机号不开放修改 |

已有接口遵循 `documents/后端接口文档.md` 的 `{code,message,data}` 响应；分页为 `{items,page,size,total}`。HTTP 失败、业务失败、HTML 或不完整分页都会显示错误，不能变成空列表或成功提示。

`src/api/capabilities.ts` 已在真实数据库与浏览器验证后开放管理能力；使用旧版后端会明确报错，须部署本轮后端和 V6/V7 迁移。移除权限配置页面不改变角色选择、管理员限制或后端权限校验。启动步骤见 [后端启动与验收](../documents/Web管理端后端启动与验收.md)。

## 演示模式

在登录页主动勾选“演示模式”，使用 admin 和任意非空密码。该模式不验证真实密码，不访问后端。页面始终显示演示标识。

- 用户演示新增、编辑、启停、移除状态由数据层统一保存在本地浏览器，可用“恢复演示数据”清除；用户页和团队人员使用同一份演示状态，不能作为服务器数据或安全验证证据。
- 组织和事项演示修改在当前页面会话内有效，刷新后恢复默认模拟数据。
- 切换真实/演示模式会清理身份，必须重新登录。
- 只有演示提供“移除用户”，真实后端无用户删除接口。
- 联调自检仅测试已实现的只读接口，演示模式下不执行。不会显示令牌、密码和原始个人资料。

## 手机号辅助开户与初始密码

- 新建用户先填 11 位手机号，账户名自动填入；手动修改账户名后，继续改手机号不会覆盖它，可点击“恢复手机号”重新联动。
- 重新打开新增表单会清空手机号、账户名、初始密码和手改标记；已有账号与手机号保持不变。
- 初始密码可随机生成、显示或复制；默认遮蔽。取消或保存后清理表单密码，不写入 localStorage 或本地操作日志。演示模式不会保存或验证密码。
- 真实接口接入后，创建请求同时提交独立的 username、phone 和 password；由后端验证并将密码哈希存入数据库。后端应返回用户资料，不返回密码或密码哈希。
- 用户管理、phone 等字段与 BCrypt 入库已通过真实数据库联调。密码重置、账号启停及资料变更撤销旧会话；当前登录账号自身变更后可能需要重新登录。具体约定见 documents/后端接口文档.md 第 3.1、15 节。

## 路由

- `/login`：登录。
- `/users`：用户管理或接口待接入提示。
- `/org`：组织结构、团队人员弹窗、审计查询与操作详情。
- `/matters`：左侧独立入口“公司十大事项”，维护标题、备注、排序和开始/截止时间。
- `/debug`：已实现接口的只读自检。
- 原 `/logs`、`/stats` 不恢复，访问按不存在页面处理。

## 界面与用户列表

- 页面采用深色导航、浅灰内容区和青蓝操作色，统一文字层级与线条图标；窄屏保留完整导航，宽表格在自身容器内横向滚动。登录页在桌面采用双栏，窄屏收起介绍区。
- 用户列表合并姓名与账号、部门与团队，保留编辑和详情入口；在用户详情中执行启停、重置密码及仅演示模式的移除，危险操作需确认。
- 用户搜索、角色/状态筛选和分页统一通过 `GET /users` 的查询参数处理，每页 10 人，人数使用服务器返回的当前查询 `total`。真实模式不合并、修改或重置本地演示补丁，成功写入后重新查询服务器，失败保留表单和明确错误。
- “导出当前页”只导出当前显示页，不把第一页数据当成全量；移除最后一页最后一人时自动返回有效页码。
- 弹窗覆盖整个视口，限制键盘焦点、锁定背景滚动并在关闭后恢复焦点；长表单在弹窗内部滚动，取消、保存及错误提示位置统一。
- 真实部门创建使用 GET /companies 返回的唯一公司 ID，归属不明时禁用创建，不默认写入公司 1。公司、部门和团队返回完整元数据数组；用户、审计和事项保持分页。

## 团队人员与事项时间

- 组织结构采用部门选择与团队列表布局；选择部门按稳定 ID 筛选团队，新建团队默认使用所选部门，仍可调整归属。窄屏下部门与团队上下排列。
- 在组织管理的团队列表点击“查看人员”，可按姓名或账号搜索，分页显示姓名、账号、角色和状态。真实接口复用 `GET /users?teamId=...&keyword=...&page=...&size=...`，以稳定团队 ID 筛选，响应保留组织 ID。
- 演示团队列表合并本浏览器的新增、编辑、停用和移除记录；旧演示记录仅在部门和团队名称能唯一定位时补足 ID。真实模式不读取这些本地补丁，不接受团队归属不匹配的响应。
- 事项新建、编辑分别选择开始/截止日期和 `00～23` 小时，不提供分钟选择，分钟和秒固定为 `00`。列表显示北京时间，例如 `2026-10-29 09:00`。
- `startDate` 与 `deadline` 保留字段名，内容调整为带 `+08:00` 的整点时间戳，例如 `2026-10-29T09:00:00+08:00`；允许同一整点，截止不得早于开始，也不受浏览器所在时区影响。
- 旧纯日期记录仍按日期展示，编辑时必须明确补选小时，不自动填为零点；缺失时间显示“未设置”。
- 起止时间由 V7 的 TIMESTAMPTZ 字段保存，后端独立验证北京时间整点；真实写入口已开放，保存后重新查询服务器。
- 审计支持按操作者与动作查询、分页和查看记录详情，只读展示对象、时间、结果。演示记录是固定样例，不代表真实操作已被服务端审计。

## 人工验收清单

1. 真实管理员能登录，普通角色不能进入 Web；错误密码和网络失败不进入演示。
2. 真实模式公司事项能翻页；无数据、无权限、服务故障各自显示正确状态。
3. 真实模式未实现模块说明缺口，不发管理请求、不提供可提交入口。
4. 令牌过期后回登录，权限和身份缓存清除；退出失败时仍清理本地会话并提示。
5. 演示中新建、编辑、启停用户，部门/团队归属正确；密码生成和重置交互可用。
6. 团队成员包含团队负责人和员工；搜索、分页、空团队和跨团队隔离正确，本地用户变更可在演示中回显。
7. 公司十大事项在左侧独立显示；验证仅可选择小时、新增编辑回显、缺失小时、同日倒序、跨日零点、同一整点和旧纯日期的兼容。
8. 浏览器窄窗口下检查导航、表格滚动和弹窗。
9. 导航、自检与组织标签没有日志、统计、角色权限配置、系统配置入口；审计可查询并查看具体记录，用户角色选择保留。
10. 用户数据超过一页时按后端 `total` 翻页，跨页搜索可找到目标；真实模式不显示演示账号，导出文件仅含当前页。
11. 弹窗遮罩覆盖整个窗口，Tab 不进入背景，Escape/取消后恢复焦点；390px 窗口导航可见，页面无整体横向溢出。
12. 用户详情中的启停确认可取消并恢复焦点，重置密码对话框可正常切换；部门筛选只显示所属团队，登录及四个主页面在窄屏可正常使用。
