# 项目计划与里程碑 —— 智能掌上日志系统（潘多拉 Pandora）

## 1. 计划说明

### 1.1 时间基准

- 项目第一周开始于 2026-09-11（周五）。
- 开发阶段共 10 周：2026-09-11 至 2026-11-19。
- 测试阶段在开发完成后 6 周内完成：2026-11-20 至 2026-12-31。
- 每个迭代为一个 7 天 Sprint，从周五开始、下周四结束。

### 1.2 敏捷原则

- 以 7 天 Sprint 为节奏，每个 Sprint 结束都要有可演示、可运行、可验收的增量。
- 测试左移：测试从第 1 周就开始编写用例，不把测试全部压到最后。
- 后端先定接口契约，移动端和 Web 端用 Mock 数据并行开发。
- 权限规则统一由后端定义，前端只负责展示与路由控制。
- 持续集成与验收证据：每个任务必须有运行结果、测试结果或可核验提交记录。

### 1.3 团队与分工

老师担任项目经理与产品经理，需求、产品与项目管理由老师负责。团队中的五名学生仅按技术分工：

| 成员 | 职责 |
|---|---|
| 成员1 | 后端开发：Spring Boot + MyBatis + PostgreSQL，接口、业务规则、权限过滤、定时任务 |
| 成员2 | Android 移动端：Flutter 页面、登录、日志、查看、点评、统计 |
| 成员3 | Web 管理端：React 页面、用户/组织/角色/配置、日志与统计只读 |
| 成员4 | 测试与质量：测试计划、用例、自动化、缺陷、非功能验证 |
| 成员5 | 数据库与部署运维：数据库设计与迁移、Docker、CI/CD、联调、发布、文档 |
