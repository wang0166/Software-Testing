# Pandora 移动端 V1.4.0 更新记录

- 发布范围：移动端 Flutter 前端开发/联调版（2026-10-30）。
- 导图：首页一屏四宫格，四面板各自滚动，默认可见数条，保留至多十条展示。
- 日历：某日超三条任务时折叠，点击「查看更多任务」以当前日期打开完整甘特图。
- 下属动态：点击头像可查看该成员授权的组织信息、任务与日志。
- 日志：部门 / 我的 / 我的下属 三个互不混杂的筛选视图；下属过滤依据后端已授权返回的人员 ID，而非凭部门猜测。
- 后端联调：依赖下属列表接口，包含零任务成员及可选的角色/团队字段；不暴露私人点评或未授权信息。
- 未在本环境实际执行 Flutter analyze/test/Android 编译，需在本机运行验证。
