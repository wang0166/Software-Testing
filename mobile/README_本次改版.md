# 移动端本次调整说明（1.12.0）

## 已修改

- **工作视图日历**：月/周格子内直接显示最多 2 项任务名称，不再显示任务标记小圆点。超过两项显示准确的 `+N`，点击直接打开完整甘特图；不再使用每周/每日任务内部小滚动条。日视图沿页面正常向下滚动。
- **首页每日事项**：继续使用独立的 `DailyTodoStorage` 私人待办数据；不接入公司任务或日志接口。与视图日历统一为「日期圆形高亮 + 文字条 + +N」的月历视觉。首页整体可向下滚动。首页每天的 `+N` 仅表示未在格子显示的**私人事项**，点击日期后在下方管理，不跳转公司甘特图。
- **任务清单**：收到的任务与我发布的记录合并为一张大表；来源筛选代替双页签。支持关键词、来源、执行/审核状态、任务类型、优先级、截止日期范围和排序；采用 `CustomScrollView` 懒加载行，纵向滚动使用整个表格区域，只有表格字段横向滚动。点击发布行出现「详情 / 编辑 / 撤回或删除」操作，沿用原审批接口。
- **任务状态**：面向执行人的状态选择只显示「进行中 / 已完成」；完成率与进度备注不再要求填写。原服务器进度接口仍需百分比，前端在后台兼容填入合规值；原来的历史记录、完成检查流程与后台审批规则保留。
- **任务创建**：选择任务类型时立刻以对应的彩色标签显示，不必等到列表。接收人支持姓名/账号搜索以及职务、部门、团队**组内多选 + 组间交集**过滤；支持「仅已选」「全选当前结果」「取消当前结果」，人员大名单使用按需构建的 `ListView.builder`。
- **下属及日志**：下属列表新增姓名/部门/团队/职务筛选和每批 20 人加载；下属详情任务可按关键词与两态筛选并分批显示；下属日志及工作日志总列表可按关键词、状态、日期范围过滤、排序，按 20 条逐批展开。

## 数据与权限说明

- 所有列表筛选仅在后端**已经授权返回的数据内**进行；并未新增扩大读取范围的接口。
- 编辑、撤回、删除、完成检查仍调用原有仓库/服务端审批方法，不通过纯前端绕过审核。
- 任务执行状态 UI 简化为两态，但兼容已有 `NOT_STARTED`、`BLOCKED` 等旧数据，旧记录不会被清空。
- 部门/团队标签在当前人员接口只含 ID 时以「部门 ID / 团队 ID」显示；若要真实名称，需要后端提供组织名称字段或映射接口。
- 筛选当前是客户端对已返回的记录进行处理；如果实际生产后端采用分页且有数万条记录，应该进一步增加服务端分页、服务端搜索与筛选参数，避免仅搜索已加载的页面。

## 验证与运行

当前生成环境无 Flutter / Dart SDK，未执行 `flutter analyze`、`flutter test` 或 Android APK 构建；仅做了源文件静态括号检查和工程文件完整性检查。旧版针对日历内部滚动与双页签的冲突测试已按照新行为更新。请在安装 Flutter 的电脑上执行：

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

若使用原生产接口，请重点验证发布记录接口可用性、权限范围、组织筛选、实际设备上的小屏排版，以及完成任务是否符合服务器审核限制。
