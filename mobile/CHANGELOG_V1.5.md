# Pandora 移动端 V1.5.0（甲方最新任务日历交互）

日期：2026-10-30。开发/联调版。

## 改动范围

1. **日历只展示任务**：月视图、周视图、日视图和甘特图只消费当前登录人有权查看的接收任务；不再请求会同时返回日志标记和日志数量的日历汇总接口。删除日历中「有日志」图例、日志红点、日志计数和其他日志状态展示。原「日志」主导航保持原样。
2. **每日最多露出 3 条任务**：保留 V1.4 超量折叠逻辑，「查看更多任务」作为文字链接打开完整甘特图。
3. **任务创建统一入口**：在「视图」页右下方固定保留带文字的「＋ 创建任务」主操作。默认日历即可创建，任务清单、下属动态、统计看板也可创建；任务清单自身不再出现重复加号；取消创建不会重置日历选择，提交成功后才刷新数据。
4. **保留审核流程**：入口打开原有 `DispatchPage`，继续允许选择公司成员、分钟级起止日期、任务类型及提交审核申请；并未绕过后端审批。
5. **滚动安全区**：日历、下属动态、统计看板留出底部滚动空间，减少悬浮按钮遮挡末尾内容的机会。

## 本版不改

- 导图首页四宫格拼图布局；日志页的「部门日志/我的日志/我的下属」独立筛选；头像拍照；下属详情；主导航五项顺序。
- Spring Boot 接口、PostgreSQL 数据库、角色权限规则。

## 已知限制与验收

- 真正的全公司任务派发和审核仍取决于后端是否实现 `/tasks/dispatch-requests`、公司成员查询及审批权限校验；演示模式不会模拟真实后端批准。
- 本环境无 Flutter SDK，未实际执行 Flutter analyze/test/run；请在项目本机运行验证。

## V1.5.1 — 任务区域滚动增强

- 月/周视图每周任务横条区域最多同时展示 3 条轨道；超过时区域内部上下滑动查看余下轨道，不再丢弃任务。
- 日视图同日超过 3 条任务时保留 3 条高度的任务列表，允许单独上下滚动查看全部。
- 两种场景均继续显示文字链接「还有 N 项任务 · 查看完整甘特图」，点击可进入原有独立甘特图页面。
- 日历仍只展示任务，不显示日志有无或日志提交状态；不修改任务权限、创建派发流程和后端接口。
