# 潘多拉移动端 V1.11.0 · 甲方 2026-11 首页调整

目标：2026-11-13（下周五）前发版。是否能正式发版须通过真机验收和后端联调。

## 本次需求逐项
1. 底部「导图」改为「首页」，「视图」改为「公司」；其余导航保持「日志 / AI地图 / 我的」，公司页仍默认日历。
2. 从首页移除「个人10大信息」「个人日志」卡片；工作日志功能不删除，仍在「日志」。
3. 「公司10大重要事项」更名为「事件纪」，仍通过 `/api/company-matters` 获取，最多展示 10 条。
4. 「公司10大派发任务」更名为「任务看板」，读取**当前执行人收到**的 `/api/tasks/received`，显示该执行人的任务并可点开任务详情。后台必须以当前认证身份限制返回数据。创建申请未审批前不计入任务看板。
5. 首页下半区域新增「每日事项」：月视图，可自由选择日期、创建/编辑/删除/勾选完成，事项和公司任务、任务审批、日志完全独立。

## 每日事项的数据范围
- **当前可运行版本：本机持久化** `shared_preferences`，按登录用户 ID 分开。退出登录不清除该用户事项。
- 不将个人事项写入工作日志/任务；不影响任务数量、审批、任务甘特图或员工统计。
- **上线前需甲方明确**是否要求跨设备同步、数据备份、管理端查看。若需要，后端应增加个人事项接口：
  - `GET /api/daily-items?month=YYYY-MM`
  - `POST /api/daily-items` （date/title/note）
  - `PATCH /api/daily-items/{id}` （date/title/note/completed）
  - `DELETE /api/daily-items/{id}`
  - 服务端只能按认证用户本人读写，不允许通过传入任意 userId 访问其他员工。
  - 未对接前不能宣称每日事项已跨设备同步。

## 发版核查
- `flutter analyze` 无 error；`flutter test` 通过；Pixel6 和 Android 真机验证。
- 事件纪/任务看板/每日事项同屏，无个人十大与日志卡片。
- 普通员工能看到本人被派发任务，不能看到非本人任务；新发布的待审核任务不得提前出现在任务看板。
- 每日事项年月日选择、跨月、增删改、完成勾选、退出登录重登、不同账号隔离均正常。
- “公司”页仍默认日历（公司任务），不会把个人每日事项混入任务日历。
- 老版日志、下属异常红点与任务未读蓝点继续可用。

变更仅限 Flutter；未改 Spring Boot / PostgreSQL 数据结构。
